## [0.1.0] - 2026-XX-XX

### 新增
- ✨ 项目初始化
- ✨ 基础 GUI 界面框架
- ✨ 主窗口类 `Main`
- ✨ 六个软件类别页面：
  - 音乐软件（music.py）
  - 视频软件（video.py）
  - 输入法（input.py）

## 版本说明

### 版本号规则

版本号格式：`主版本号。次版本号.修订号`

- **主版本号**: 重大功能更新
- **次版本号**: 向后兼容的功能性新增
- **修订号**: 向后兼容的问题修正

### 标识符说明

- `[未发布]`: 开发中，尚未发布
- `[当前]`: 最新稳定版本
- `[已废弃]`: 不再维护的旧版本
