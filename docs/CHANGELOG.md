## 版本说明

### 版本号规则
本项目采用语义化版本号：`主版本号。次版本号.修订号`

- **主版本号**: 重大功能更新或不兼容的 API 修改
- **次版本号**: 向后兼容的功能性新增
- **修订号**: 向后兼容的问题修正

### 发布周期
- **开发版**: 随时发布，包含最新功能（可能不稳定）
- **稳定版**: 随时发布，经过充分测试

## 已知问题

### v0.2.0 已知问题
1. **WiFi 检测需要管理员权限**
   - 影响：部分用户无法使用 WiFi 检测功能
   - 临时方案：以管理员身份运行程序
   - 计划修复：v0.3.0

2. **不支持直接下载**
   - 影响：只能跳转到官网下载
   - 临时方案：手动在官网下载
   - 计划修复：v0.3.0

3. **软件数据需要手动更新**
   - 影响：软件版本更新时需要手动修改 JSON
   - 临时方案：定期更新 data.json
   - 计划修复：v0.4.0

## 安全更新

### v0.2.2 安全性
- ✅ 无外部 API 调用，数据安全
- ✅ 本地数据存储，无隐私泄露风险
- ⚠️ 官网跳转需用户自行判断网站安全性

### 安全建议
1. 仅从官方渠道下载软件
2. 不要修改 data.json 中的下载链接
3. 定期检查软件官网的安全证书
